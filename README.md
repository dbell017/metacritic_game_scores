# Metacritic Games Analysis (2011–2019)

An exploratory analysis of critic and user review scores for over 5,500 games released between 2011 and 2019, using data sourced from Kaggle.

For a full write-up of findings and recommendations, see `Data Analysis and Insights Brief - Videogame Metacritic Scores.pdf`.

## Tools

Python, pandas, numpy, matplotlib, seaborn

## Repository Contents

| File | Description |
|------|-------------|
| `Metacritic_games.ipynb` | Jupyter Notebook with full analysis and visualizations |
| `metacritic_games.csv` | Original dataset |
| `metacritic_games_cleaned.csv` | Cleaned dataset with genre reassignments and engineered features |
| `Data Analysis and Insights Brief - Videogame Metacritic Scores.pdf` | Written summary of findings and recommendations |
